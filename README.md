# OSK-Raspberry-Trixie

Экранная клавиатура для Raspberry Pi OS Trixie (labwc, Wayland): wvkbd с широкой раскладкой EN/RU,
значок раскладки `osk-tray` и история буфера обмена `clipd` (синхронизация через Syncthing).

| Файл | Назначение |
|---|---|
| `osk` | управление клавиатурой: `osk toggle`, `osk restart`, `osk build`, `osk layer en|ru`, `osk slot` |
| `osk-tray` | значок раскладки: ЛКМ - язык (значок плавающий, перетаскивается), двойной клик - показать/скрыть, СКМ - история буфера, ПКМ - меню (над клавиатурой, если она на экране) |
| `clipd` | история буфера обмена: окно можно двигать, масштабировать, закрывать; двойной клик по записи вставляет её в прежнее окно |
| `osk.toml` | общий конфиг (-> `~/.config/osk/osk.toml`) |
| `patch_keyboard.py`, `mkwide.py`, `wide.toml` | сборка wvkbd-wide (upstream commit bbecd99) |
| `ICONs/tray/` | картинки значка |

Установка: скопировать `osk osk-tray clipd` в `~/.local/bin/`, `osk.toml` в `~/.config/osk/`, `ICONs` рядом с `osk-tray`
на Pi командой `osk build`.
Автозапуск: `osk autostart on` (клавиатура свёрнута + значок), выключить: `osk autostart off`.
Значок плавающий: перетащите его левой кнопкой, позиция запоминается. `osk-tray hide|show|toggle` - управление клавиатурой из терминала.

## Шаблоны
`clipd tpl` - окно шаблонов (в меню значка: «Шаблоны...»). Шаблон = файл `.txt` или без расширения в папке
`templates_dir` (по умолчанию `<sync_dir>/templates`), подпапки показываются как папки, симлинки на папки и файлы работают.
Выбор вставляет текст в активное окно (терминалы определяются автоматически - Ctrl+Shift+V) или копирует в буфер.
**Управление шаблонами в окне:** «＋ Шаблон» (имя, папка, текст; можно сразу создать подпапку), «＋ Из буфера» (текст из буфера обмена),
«＋ Папка», «Изменить» (текст и имя; для папки - переименование), «Удалить» (второе нажатие подтверждает). То же - в контекстном меню (правая кнопка).
Вложенность папок любая. Из окна истории буфера: «В шаблоны» (кнопка и контекстное меню) - выбрать папку и имя.
Вставка шаблона возвращает прежнее содержимое буфера и не пишет шаблон в историю (`templates_restore_clipboard`).
Вставка (`paste_method`): `uinput` (Ctrl+V от виртуальной клавиатуры ядра, по умолчанию), `keys` (Ctrl+V через wtype), `type` (печать текста).

**jbak2.** Папки из `templates_extra` (по умолчанию `~/Syncthing/jbak2/templates`) показываются в окне как папки (читаются все текстовые файлы).
`clipd tpl-export [--force] [--no-prune]` копирует НАШИ шаблоны в `templates_export_dir` (по умолчанию `~/Syncthing/jbak2/templates/trixie`):
имя без `.txt`, без перевода строки в конце. Шаблоны самого jbak2 не копируются и не дублируются (файлы из `templates_extra`, в т.ч. через симлинки, пропускаются;
подпапка экспорта в окне скрыта). Файл, изменённый в папке экспорта позже нашего (правка на телефоне), не перезаписывается без `--force`.
Удаление лишнего (`templates_export_prune`) - только внутри папки экспорта. Экспорт в корень чужой папки запрещён.
Все пути и поведение - в `osk.toml`, секция `[clipboard]`.
