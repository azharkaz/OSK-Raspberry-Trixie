# OSK-Raspberry-Trixie

Экранная клавиатура для Raspberry Pi OS Trixie (labwc, Wayland): wvkbd с широкой раскладкой EN/RU,
значок раскладки `osk-tray` и история буфера обмена `clipd` (синхронизация через Syncthing).

| Файл | Назначение |
|---|---|
| `osk` | управление клавиатурой: `osk toggle`, `osk restart`, `osk build`, `osk layer en|ru`, `osk slot` |
| `osk-tray` | значок раскладки: ЛКМ - язык (значок плавающий, перетаскивается), двойной клик - показать/скрыть, СКМ - история буфера, ПКМ - меню (над клавиатурой, если она на экране) |
| `clipd` | история буфера обмена: окно можно двигать, масштабировать, закрывать; двойной клик по записи вставляет её в прежнее окно |
| `osk.toml` | общий конфиг (-> `~/.config/osk/osk.toml`) |
| `patch_keyboard.py`, `mkwide.py`, `wide.toml` | сборка wvkbd-wide (upstream commit bbecd99) |
| `ICONs/tray/` | картинки значка |

Установка: скопировать `osk osk-tray clipd` в `~/.local/bin/`, `osk.toml` в `~/.config/osk/`, `ICONs` рядом с `osk-tray`
на Pi командой `osk build`.
Автозапуск: `osk autostart on` (клавиатура свёрнута + значок), выключить: `osk autostart off`.
Значок плавающий: перетащите его левой кнопкой, позиция запоминается. `osk-tray hide|show|toggle` - управление клавиатурой из терминала.

## Шаблоны
`clipd tpl` - окно шаблонов (в меню значка: «Шаблоны...»). Шаблон = файл `.txt` или без расширения в папке
`templates_dir` (по умолчанию `<sync_dir>/templates`), подпапки показываются как папки, симлинки на папки и файлы работают.
Выбор вставляет текст в активное окно (терминалы определяются автоматически - Ctrl+Shift+V) или копирует в буфер.
**Управление шаблонами в окне:** «＋ Шаблон» (имя, папка, текст; можно сразу создать подпапку), «＋ Из буфера» (текст из буфера обмена),
«＋ Папка», «Изменить» (текст и имя; для папки - переименование), «Удалить» (второе нажатие подтверждает). То же - в контекстном меню (правая кнопка).
Вложенность папок любая. Из окна истории буфера: «В шаблоны» (кнопка и контекстное меню) - выбрать папку и имя.
Вставка шаблона возвращает прежнее содержимое буфера и не пишет шаблон в историю (`templates_restore_clipboard`).
Вставка (`paste_method`): `uinput` (Ctrl+V от виртуальной клавиатуры ядра, по умолчанию), `keys` (Ctrl+V через wtype), `type` (печать текста).

**jbak2.** Папки из `templates_extra` (по умолчанию `~/Syncthing/jbak2/templates`) показываются в окне как папки (читаются все текстовые файлы).
`clipd tpl-export [--force] [--no-prune]` копирует НАШИ шаблоны в `templates_export_dir` (по умолчанию `~/Syncthing/jbak2/templates/trixie`):
имя без `.txt`, без перевода строки в конце. Шаблоны самого jbak2 не копируются и не дублируются (файлы из `templates_extra`, в т.ч. через симлинки, пропускаются;
подпапка экспорта в окне скрыта). Файл, изменённый в папке экспорта позже нашего (правка на телефоне), не перезаписывается без `--force`.
Удаление лишнего (`templates_export_prune`) - только внутри папки экспорта. Экспорт в корень чужой папки запрещён.
Все пути и поведение - в `osk.toml`, секция `[clipboard]`.

## Плавающая клавиатура
Уменьшенная копия клавиатуры, пропорционально масштабируется (`[floating] scale`, доля от полной), шрифт клавиш НЕ уменьшается.
В левом верхнем углу - круглая янтарная кнопка: клик сворачивает клавиатуру в кружок поверх всех окон (в т.ч. полноэкранных), ещё клик - разворачивает;
кнопку можно тащить - клавиатура едет вместе с ней, положение запоминается.
Кнопка **Menu** на обеих клавиатурах: короткое нажатие - меню значка (там «Плавающая / полная клавиатура», размер, шаблоны, панель и т.д.), удержание - настоящая клавиша Menu.
То же меню - правый клик по значку раскладки (пункты в `[[tray.menu]]`).

    osk float on|off|toggle|status      osk float size up|down|0.6|reset

Настройки - секция `[floating]` в `osk.toml`. **После обновления:** распаковать в папку проекта, `osk build` (пересобирает wvkbd с новыми патчами; нужны `mkwide.py`, `wide.toml`, `patch_keyboard.py`), `osk restart`, `osk-tray restart`.

## Сторож панели задач
`osk-tray` следит за процессом `xfce4-panel`: пропала дольше `panel_grace_s` - запускает заново (не чаще `panel_max_restarts` за 5 минут).
Пока на экране полноэкранное окно, панель не поднимается (не перекроет игру/видео) - вернёт после выхода из полного экрана.

    osk-tray panel restart              osk-tray panel watch on|off|toggle|status

Отключение сторожа сохраняется; в меню значка: «Перезапустить панель задач», «Сторож панели: вкл / выкл». Параметры - `[tray] panel_*`.

## Update 21
**Плавающий значок (круглая кнопка).** Левый клик - свернуть/развернуть (после паузы `double_click_ms`, чтобы отличить от двойного); двойной левый - история буфера; средний - шаблоны; правый - меню (то же, что у значка языка и кнопки Menu). Состояние клавиатуры при двойном/среднем/правом не меняется. Команды - `[floating] right_click / double_click / middle_click`. Перетаскивание работает и в VNC (запасной режим по координатам внутри окна, если относительные смещения указателя не приходят).

**Меню со состоянием.** Пункт с `state = "panel_watch"` или `"float"` берёт подпись из `label_on` / `label_off` (✅ / ⬜).

**Чёткость окон истории и шаблонов.** `[clipboard] font, font_size, font_weight, text_color, font_hint, font_antialias`. Для лучшей отрисовки нужен `python3-gi-cairo`: `sudo apt install python3-gi-cairo`.

**Страницы символов и эмодзи.** Удержание кнопки EN/RU (≥ 450 мс) открывает 9 страниц: 1 - символы и валюты + верхний ряд Undo/Redo/Find/All/Save/Open/New/Print/Bold/Ital/Undl/Close (Ctrl+...), 2 - стрелки, фигуры, знаки, 3-9 - цветные эмодзи. Кнопки на тех же местах; Shift листает по кругу, «abc» возвращает на буквенную раскладку. Страницы описаны в `wide.toml` (`[[sym]]`, 46 символов на страницу), нужен `osk build`. Для цветных эмодзи нужен шрифт `fonts-noto-color-emoji`.

## Update 25
- Окно настроек теперь обычное окно (двигается и растягивается мышью как любое другое, размер запоминается в ~/.cache/osk/settings-win.json); вкладки слева, всегда помещаются. `[system] settings_window = "layer"` - прежний режим поверх клавиатуры (без перемещения).

Из терминала: `osk fixperms`. Отключается: `[system] auto_fix_perms = false`.
